# MainCrafts Task 5 – Customer Sales Analysis
## Project Overview
This project is part of the MainCrafts Data Analytics & Business Intelligence Internship.
The project focuses on advanced DAX calculations, customer ranking, Pareto Analysis, ABC customer classification, and dashboard performance analysis using Microsoft Power BI.
## Tools Used
- Microsoft Power BI
- DAX
- Power BI Performance Analyzer
## Key Features
- Customer Sales Analysis
- Customer Ranking using RANKX
- Cumulative Sales Calculation
- Pareto Analysis
- ABC Customer Classification
- KPI Cards
- Dashboard Performance Analysis
## Project Files
- Power BI Dashboard (.pbix)
- DAX Measures (.txt)
- Portfolio Case Study (.pdf)
- Dashboard Screenshot (.png)
- Performance Analyzer JSON files
## Dataset
Superstore Sales Dataset containing approximately 9,800 records.
**Note:** The dataset does not contain a Profit column. Therefore, the project focuses on Sales Analysis.
